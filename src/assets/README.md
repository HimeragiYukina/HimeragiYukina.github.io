# Asset organization

- `site/`: site-wide identity and interface assets
- `research/`: publication figures and downloadable papers, grouped by project
- `fluid-simulation/`: captured fluid-simulation demonstrations
- `mods/`: game-mod media, grouped by mod and then by asset role
- `photography/display/`: optimized images bundled with the website
- `photography/originals/`: full-resolution photography sources
- `fonts/`: self-hosted web fonts and generated font subsets
